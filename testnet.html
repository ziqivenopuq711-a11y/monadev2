Monad Testnet

Live since Feb 2025

The Monad Testnet is the fully functional pre-production environment for developers, validators, and users to test dApps, run nodes, and explore the network before mainnet. Test MON tokens are freely available from the faucet — no real funds at risk.

Add via MetaMask

  1. Open MetaMask and click the network selector at the top.
  2. Select Add a network → Add a network manually.
  3. Enter the network details from the table above.
  4. Click Save and switch to Monad Testnet.

Alternatively, visit the Monad Testnet page on Chainlist.org for one-click wallet setup.

Activities

What to Do on the Monad Testnet

🔨

Deploy Smart Contracts

Deploy any Solidity smart contract to the Monad Testnet. Use Foundry, Hardhat, or Remix — the same workflow as Ethereum. Test parallel execution effects under load by submitting many transactions concurrently from multiple wallets.

🧪

Interact with dApps

Dozens of dApps are already live on the Monad Testnet — DEXs, lending protocols, NFT minters, and more. Browse the ecosystem and provide feedback to developers ahead of mainnet launch to help shape the final product quality.

📈

Performance Testing

Benchmark your smart contracts by sending high-volume transaction bursts. Observe how Monad's parallel EVM handles concurrent state access, how conflict rates vary with your contract design, and how gas estimation behaves under load.

🔍

Explore the Network

Use the Monad Testnet Explorer to watch blocks fill with transactions in real time, decode contract interactions, inspect event logs, and monitor gas price trends — all to develop intuition for how the live network behaves.

Reporting Issues

Found a bug or unexpected behaviour on the Monad Testnet? Report it in the #testnet-issues channel on Discord or open a GitHub issue in the monad-lab organisation. Include your transaction hash, contract address, and a description of the expected vs. actual behaviour. Well-reported issues are eligible for bounty rewards.
