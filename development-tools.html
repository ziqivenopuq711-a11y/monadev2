Frameworks

Smart Contract Development

Monad is fully EVM-compatible. Every tool you use for Ethereum development works on Monad without modification — simply update the network configuration.

🔨

Foundry

The fastest Ethereum development toolkit. Write tests in Solidity, run fuzz campaigns, and deploy to Monad with forge and cast. Update foundry.toml with the Monad RPC URL.

⚙

Hardhat

Flexible JavaScript-based framework popular in the Ethereum ecosystem. Add the Monad network to hardhat.config.ts, run npx hardhat deploy, and your contracts are live on Monad.

Browser-based Solidity IDE with one-click deployment. Select "Injected Web3" or "Custom RPC" and enter the Monad Testnet endpoint to deploy directly from the browser — no local setup required.

Libraries & SDKs

JavaScript / TypeScript SDKs

Interact with Monad from any JavaScript or TypeScript application using the same libraries you already know from Ethereum development.

👣

ethers.js v6

The gold-standard Ethereum library for web and Node.js. Connect to Monad by initialising a provider with the Monad JSON-RPC URL — all contract interactions, signing, and event listening work identically.

import { JsonRpcProvider } from "ethers";
const provider = new JsonRpcProvider(
  "https://rpc.monad.xyz/testnet"
);
🛡

viem

A modern, TypeScript-first Ethereum client library optimised for type safety and tree-shaking. Add Monad as a custom chain definition and use the full viem API surface against Monad's RPC with zero extra configuration.

import { createPublicClient, http } from "viem";
import { monadTestnet } from "./chains";
const client = createPublicClient({
  chain: monadTestnet,
  transport: http()
});
📈

Wagmi

React hooks for Ethereum — wallet connection, contract reads/writes, transaction watching, and more. Wagmi's chain registry includes Monad Testnet. Import monadTestnet from wagmi/chains to connect your dApp UI.

🎓

web3.js

The classic JavaScript Ethereum library. Instantiate a Web3 instance with the Monad RPC endpoint and all existing web3.js code works without changes — useful for maintaining legacy applications during migration.

Debugging & Testing

Test, Debug, and Verify Contracts

Monad exposes the full Ethereum JSON-RPC debug namespace, giving you access to detailed transaction traces, opcode-level execution logs, and state diffs — essential for diagnosing issues in complex DeFi protocols or multi-contract interactions.

Trace a Transaction

Use debug_traceTransaction to get an opcode-by-opcode execution trace of any transaction on the network. Combine with Foundry's cast run or Hardhat's hardhat-tracer plugin for a richer developer experience.

cast run --rpc-url https://rpc.monad.xyz/testnet \
  0xYOUR_TX_HASH

Local Forking

Fork the Monad Testnet locally to simulate state without broadcasting real transactions. Foundry's Anvil supports this natively:

anvil --fork-url https://rpc.monad.xyz/testnet

Contract Verification

Verify your contract source code on the Monad Explorer so users and auditors can read and interact with it transparently. Foundry supports verification in one command:

forge verify-contract \
  --chain-id 10143 \
  --verifier blockscout \
  --verifier-url https://explorer.monad.xyz/api \
  0xCONTRACT_ADDRESS \
  src/MyContract.sol:MyContract

Tip: Because Monad processes transactions in parallel, contracts that modify shared state (e.g. AMM pools) may behave differently under high load than on a sequential chain. Use Foundry's fuzz testing and invariant testing to surface edge cases before deploying to mainnet.
