Explorer Features

What You Can Do with the Monad Explorer

🔍

Transaction Search

Look up any transaction by its hash to see the sender, receiver, value transferred, gas used, input data, emitted events, and execution status. Internal transactions from contract calls are shown in a hierarchical call trace.

👤

Address & Contract Inspection

View the full transaction history, token balances, and deployed bytecode for any address. For verified contracts, read and write functions directly from the explorer UI using your connected wallet — no code required.

📊

Token Tracker

Browse ERC-20, ERC-721, and ERC-1155 tokens deployed on Monad. See total supply, holder counts, transfer history, and price data for listed assets. Ideal for monitoring your deployed token contracts.

📋

Contract Verification

Submit your smart contract's Solidity source code to be verified and published on the explorer. Once verified, users and auditors can read the code, inspect ABI functions, and interact with the contract directly from the explorer.

🔥

Gas Tracker

Monitor current gas prices across slow, standard, and fast tiers. The gas tracker updates in real time, helping you estimate transaction costs and optimise gas parameters in your applications for the best user experience.

🔌

Event Log Decoder

Event logs are automatically decoded for verified contracts, displaying human-readable parameter names and values instead of raw hex. Filter by event topic to isolate specific contract events within a block or time range.

Explorer API

The Monad Explorer exposes a RESTful API compatible with the Etherscan API v2 standard. Use it to programmatically query transaction data, contract ABIs, event logs, and token transfers in your applications.

# Get contract ABI for a verified contract
curl "https://explorer.monad.xyz/api?module=contract&action=getabi&address=0xCONTRACT_ADDRESS"
